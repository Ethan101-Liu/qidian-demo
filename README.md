# 起点 · 总有一个世界

起点中文网与起点读书的非官方单页互动介绍设计。桌面优先，纯 HTML、CSS、JavaScript；没有二级页面，也没有服务端依赖。

## 体验

- C 版白衣剑仙连续视频开场与滚动转场：开场隐藏整排导航，结束时导航与正文一起显现；支持跳过和反向滚动。
- A 版水墨技能书光标：移动带动独立纸页连续翻动，停止后完成当前翻页；弹窗内也可使用。
- B 版沉浸剧场：真实书封弧形舞台、鼠标视差、书封悬浮反馈。
- 12 种题材：悬停文字即同步切换背景、文案、标签与真实作品；更多题材在页内展开，支持键盘操作。
- 页内作品简介：原生 dialog，支持按钮、遮罩及 Escape 关闭，并恢复焦点与浏览位置。
- 起点读书展示：官方品牌视觉与 App Store 的本章说、有声截图切换。
- 下载按钮只产生按压与光效，不跳转、不下载、不弹窗。
- 键盘可操作，遵循系统减少动态效果设置。

开场已接入用户提供的约 12 秒、1280×720 视频：背身、转身持书、挥书及纸页掠镜头。网页版本为静音 H.264、每帧可独立解码，便于正反向滚动定位；`opening-video.js` 只定位最新滚动目标。画面使用 `object-fit: cover` 居中满屏，屏幕比例不同会裁切边缘，不添加黑边。首帧作为加载和失败时的回退。制作要求与当前素材记录见 [OPENING-BRIEF.md](OPENING-BRIEF.md)。

## 本地预览

需要 Node.js；无需安装 npm 依赖。

```sh
node serve.mjs
```

打开 http://127.0.0.1:4173 。编辑后刷新浏览器。不要通过 `file://` 打开，以免不同浏览器的本地文件限制影响体验。

## GitHub Pages

将此目录作为仓库根目录。可选其一：

1. 在 Settings → Pages 选择从 `main` 分支的根目录发布；`.nojekyll` 已包含。
2. 在 Settings → Pages 选择 GitHub Actions，使用附带的 `.github/workflows/pages.yml`；工作流仅打包页面与静态素材。

所有站点资源使用相对路径，可部署到 `https://用户名.github.io/仓库名/` 子目录。当前只是本地版本，尚未创建或公开 GitHub 仓库，也未部署。

工作流依据 [GitHub Pages 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages) 配置。

## 内容维护

`app.js` 中 `books` 维护作品信息，`genres` 维护题材文案、背景与选书。书籍信息在 2026-10-09 核实，固定维护，不是实时排行榜或个性化推荐。部分简介是根据题材和官方资料写的简短概述。

图片均随站点部署，不依赖运行时请求第三方网站；非首屏图片延迟加载。
